# 无关菜单清理说明

本轮没有连接或修改任何生产数据库，也没有自动执行菜单删除 SQL。

## 建议清理范围

后续应在测试环境先查询 `system_menu`，按菜单名称、路由和权限标识确认后，清理以下已移除模块的菜单及角色菜单关联：

- AI、工作流 BPM、CRM、ERP、会员、报表、MES、WMS
- 商城、商品、交易、营销、支付、公众号、IoT

## 建议步骤

1. 备份 `system_menu` 与角色菜单关联表。
2. 查询 `component`、`path`、`permission` 中包含上述模块前缀的菜单。
3. 递归确认父子菜单范围，避免删除 `system`、`infra`、`jijian` 菜单。
4. 先删除对应角色菜单关联，再删除已确认的无关菜单。
5. 在测试环境验证登录、权限、纪检录入、查询和文件上传后，再安排生产变更。

项目初始化 SQL 中仍存在通用/历史模块菜单数据，尤其是 `sql/dm/ruoyi-vue-pro-dm8.sql`。本轮按要求只记录风险，不修改初始化 SQL。
